#  PROJETO GREEN BELT: OTIMIZAÇÃO DO ATENDIMENTO - HOSPITAL SCQM

Este repositório contém o projeto de consultoria Lean Six Sigma (Green Belt) focado na redução do Tempo de Espera do Paciente e otimização da Capacidade de Atendimento do Hospital Santa Casa de Quem Grita Mais.

O projeto é estruturado na metodologia **DMAIC** e utiliza **Engenharia de Dados (Python/Streamlit)** para automatizar as análises estatísticas e implementar um sistema de controle sustentável.
